# 🌙 Moon-Hub

Üdvözöllek a **Moon-Hub** repómban! 👋

## 📱 Mi ez?

Ez a repó az általam fejlesztett **Android alkalmazás** otthona.  
Az app célja, hogy egyszerű és könnyen használható legyen mindenki számára.

## 📲 Letöltés

Az alkalmazást az alábbi lépésekkel tudod telepíteni:

1. Menj a [Releases](https://github.com/RedfluffyMoon/Moon-Hub/releases) oldalra
2. Töltsd le a legújabb `.apk` fájlt
3. Telepítsd a telefonodra
4. Engedélyezd az **"Ismeretlen forrásból való telepítés"** opciót a beállításokban
